Authentication

All API requests require an API key passed in the X-API-Key header. {% if user %} You can generate one in Settings. {% else %} Sign up to get one. {% endif %}

# Example: authenticate with your API key curl -H "X-API-Key: sr_your_key_here" \ {{ app_url }}/api/v1/monitors
# pip install requests import requests headers = {"X-API-Key": "sr_your_key_here"} r = requests.get("{{ app_url }}/api/v1/monitors", headers=headers) print(r.json())
// Node.js / browser const res = await fetch("{{ app_url }}/api/v1/monitors", { headers: { "X-API-Key": "sr_your_key_here" } }); const data = await res.json(); console.log(data);

Response format: All endpoints return JSON with this shape:

{ "data": { ... }, // The response payload (object, array, or null) "error": null, // Error message string, or null on success "meta": { ... } // Optional metadata (total count, pagination, etc.) }

Error responses use standard HTTP status codes:

CodeMeaning
401Missing or invalid API key
403Plan limit exceeded
404Resource not found
422Invalid or missing request body

GET /api/v1/monitors List all monitors ▶

Returns all monitors belonging to the authenticated user.

curl -H "X-API-Key: sr_your_key_here" \ {{ app_url }}/api/v1/monitors
r = requests.get(f"{BASE}/monitors", headers=headers) monitors = r.json()["data"] for m in monitors: print(f"{m['name']}: {m['status']}")
const res = await fetch(`${BASE}/monitors`, { headers }); const { data } = await res.json(); data.forEach(m => console.log(`${m.name}: ${m.status}`));

POST /api/v1/monitors Create a monitor ▶

Create a new monitor. Checks start on the next cron cycle (~60s).

Body fieldTypeRequiredDescription
urlstringyesURL to monitor (include https://)
namestringyesDisplay name
alert_emailstringnoDefaults to account email
alert_slack_webhookstringnoSlack incoming webhook URL
keywordstringnoAlert if missing from response body
response_threshold_msintegernoAlert if response exceeds this (ms)
webhook_urlstringnoStatus change webhook (Pro only)
publicbooleannoCreate a status page (default: true)
curl -X POST \ -H "X-API-Key: sr_your_key_here" \ -H "Content-Type: application/json" \ -d '{"url":"https://example.com","name":"My Site","keyword":"Welcome"}' \ {{ app_url }}/api/v1/monitors
r = requests.post( f"{BASE}/monitors", headers=headers, json={ "url": "https://example.com", "name": "My Site", "keyword": "Welcome" } ) new_monitor = r.json()["data"] print(f"Created: {new_monitor['id']}")
const res = await fetch(`${BASE}/monitors`, { method: "POST", headers: { ...headers, "Content-Type": "application/json" }, body: JSON.stringify({ url: "https://example.com", name: "My Site", keyword: "Welcome" }) }); const { data } = await res.json(); console.log(`Created: ${data.id}`);

DELETE /api/v1/monitors/{id} Delete a monitor ▶

Permanently delete a monitor and all its check history.

curl -X DELETE \ -H "X-API-Key: sr_your_key_here" \ {{ app_url }}/api/v1/monitors/jkUVy3EYnvGx16jWT2v0
monitor_id = "jkUVy3EYnvGx16jWT2v0" r = requests.delete(f"{BASE}/monitors/{monitor_id}", headers=headers) print(r.json())
const id = "jkUVy3EYnvGx16jWT2v0"; const res = await fetch(`${BASE}/monitors/${id}`, { method: "DELETE", headers }); const { data } = await res.json(); console.log(data);

Example response (200 OK):

{ "data": { "deleted": true, "monitor_id": "jkUVy3EYnvGx16jWT2v0" }, "error": null }
ⓘ Field reference (2 fields)
FieldTypeDescription
deletedboolAlways true on success

Uptime Badges

Embed live SVG badges in your README, docs, or website. No auth required — badges are public for monitors with public: true. Cached for 5 minutes.

GET /badge/{monitor_id}.svg Uptime percentage badge ▶

Returns a shields.io-style SVG badge showing the monitor's uptime percentage. Color-coded: green (≥99.5%), yellow-green (≥99%), yellow (≥95%), red (<95%).

ⓘ Badge behavior
ThresholdColor
≥ 99.5%green
≥ 99%yellow-green
≥ 95%yellow
< 95%red
# Markdown ![Uptime]({{ app_url }}/badge/YOUR_MONITOR_ID.svg) # HTML <img src="{{ app_url }}/badge/YOUR_MONITOR_ID.svg" alt="Uptime" /> # curl (returns SVG) curl {{ app_url }}/badge/YOUR_MONITOR_ID.svg
# Download badge SVG r = requests.get("{{ app_url }}/badge/YOUR_MONITOR_ID.svg") with open("badge.svg", "w") as f: f.write(r.text)
// Fetch badge SVG const res = await fetch("{{ app_url }}/badge/YOUR_MONITOR_ID.svg"); const svg = await res.text(); console.log(svg);

Rate Limits

The API currently does not enforce strict rate limits. Please be reasonable — if you're polling, once per minute is plenty. We reserve the right to throttle abusive usage.
