No black boxes. Here's exactly what we check.

Every monitor type runs a deterministic check cycle. Here's what happens under the hood.

HTTP / HTTPS

  • GET (or custom method) to your URL
  • Checks status code matches expected
  • Optional keyword match in response body
  • Alert if response exceeds threshold ms
  • Retries once before marking down

SSL Certificate

  • Checks certificate validity on every run
  • Alerts when expiry is within your threshold
  • Catches mismatched domains & chains
  • Works on any port (443, 8443, custom)

Heartbeat / Cron

  • Your job pings a unique URL on each run
  • Missed ping after interval + grace period = alert
  • Token-secured URL (not just an ID)
  • Perfect for scheduled scripts & background jobs

JSON / API

  • Full request with custom headers & auth
  • Assert on JSON fields with dot-path selectors
  • Supports equals, contains, gt/lt comparisons
  • Alerts on assertion failure even on a 200 OK
