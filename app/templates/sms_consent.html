1. Overview

StatusRooster (statusrooster.com) is an uptime monitoring service. SMS alerts are available on all plans and send transactional text messages when a user's monitored website or API goes down or recovers. Messages are strictly transactional — we never send marketing or promotional SMS.

2. Complete Opt-In Flow (with Screenshots)

SMS opt-in requires a multi-step, explicit consent process within the user's logged-in account. The opt-in form is at statusrooster.com/monitors/add (requires authentication). Below are exact reproductions of the in-app interface at each step.

Step 1: User navigates to Add Monitor or Edit Monitor

After logging in, users navigate to the Add Monitor or Edit Monitor form. The Notifications section shows all available alert channels.

Step 2: User toggles SMS from OFF to ON

SMS is off by default and cannot be pre-selected. The user must explicitly toggle it on.

Step 3: User enters their phone number

After toggling SMS on, a phone number input field appears. The user enters their phone number in international format (e.g., +15551234567). Client-side validation confirms the number matches E.164 format before submission.

Step 4: User checks the consent checkbox

Below the phone number field, an unchecked checkbox with the full consent disclosure must be checked before the form can be submitted. The checkbox is required — the form cannot be saved without it. The exact consent text is:

"By checking this box, you agree to receive SMS alerts from StatusRooster regarding monitor status updates (down/recovery). Message frequency varies. Message and data rates may apply. Reply STOP to opt out or HELP for assistance. Consent is not a condition of purchase. Privacy Policy · Terms of Service"

This disclosure includes:

  • Explicit checkbox (unchecked by default, required to submit)
  • Description of message content (monitor status updates — down/recovery)
  • Message frequency disclosure ("varies")
  • "Message and data rates may apply"
  • Opt-out instructions ("Reply STOP to opt out")
  • Help instructions ("Reply HELP for assistance")
  • "Consent is not a condition of purchase"
  • Link to Privacy Policy
  • Link to Terms of Service

Step 5: User submits the form

The user clicks "Create Monitor" or "Save Changes". By saving with SMS enabled and a phone number entered, the user explicitly consents to receive SMS alert notifications from StatusRooster.

Step 6: Confirmation SMS is sent immediately

Upon first opt-in, the user receives the following confirmation text message:

3. Message Content & Frequency

All messages are prefixed with [StatusRooster] and include STOP/HELP instructions.

  • Downtime alert: [StatusRooster] ALERT: Your monitor "My Website" is DOWN. Checked at 10:45 AM UTC. Reply STOP to opt out, HELP for help.
  • Recovery notification: [StatusRooster] RECOVERY: Your monitor "My Website" is back UP. Downtime: 4 minutes. Reply STOP to opt out, HELP for help.
  • SSL expiry: [StatusRooster] ALERT: SSL certificate for myapp.com expires in 3 days. Renew now to avoid downtime. Reply STOP to opt out, HELP for help.

Frequency: Message frequency varies based on monitor activity. Typical usage is 1–10 messages per week, depending on how many monitors have SMS enabled and how often incidents occur. Users with stable services may receive zero messages for extended periods.

Message and data rates may apply.

4. How to Opt Out

Users can opt out of SMS alerts at any time using either method:

  • Reply STOP to any SMS message from StatusRooster to immediately stop all SMS notifications.
  • In-app: Edit the monitor, toggle SMS off or remove the phone number, and save.

For help, reply HELP to any SMS message or contact support@statusrooster.com.

5. Data & Privacy

  • Phone numbers are stored securely and used only for sending SMS alerts via Twilio.
  • We do not share, sell, or rent phone numbers or opt-in data with third parties for marketing or any other purpose.
  • SMS delivery is handled by Twilio. Only the phone number and message content are shared with Twilio — no other personal data.
