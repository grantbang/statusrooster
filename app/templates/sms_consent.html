SMS Alert Consent & Opt-In Flow

How StatusRooster collects user consent for SMS notifications

1. Overview

StatusRooster is an uptime monitoring service at statusrooster.com. SMS alerts are a Pro plan feature ($9/month) that sends transactional text messages when a user's monitored website or API goes down or recovers. Messages are strictly transactional — we never send marketing or promotional SMS.

2. How Users Opt In

SMS opt-in is a multi-step, explicit consent process that occurs within the user's logged-in account:

Step 1: User creates or edits a monitor

After logging in, users navigate to the Add Monitor or Edit Monitor form. The Notifications section lists available alert channels: Email, Slack, Webhook, and SMS.

Step 2: User toggles on SMS alerts

SMS is off by default. The user must explicitly toggle the SMS switch to enable it. Free plan users see "Upgrade to Pro" — they cannot enable SMS without upgrading first.

Step 3: User enters their phone number

After toggling SMS on, a phone number input field appears. The user enters their phone number in international format (e.g., +15551234567).

Step 4: User saves the form

The user clicks "Create Monitor" or "Save Changes" to submit the form. By saving with SMS enabled and a phone number entered, the user explicitly consents to receive SMS alert notifications from StatusRooster. Consent is recorded at the time of form submission.

3. Message Content & Frequency

  • Message types: Downtime alerts ("Your monitor [name] is DOWN") and recovery notifications ("Your monitor [name] is back UP"). These are strictly transactional, event-driven messages.
  • Frequency: Message frequency varies based on monitor activity. Typical usage is 1–10 messages per week, depending on how many monitors have SMS enabled and how often incidents occur. Users with stable services may receive zero messages for extended periods.
  • Message and data rates may apply.

4. How to Opt Out

Users can opt out of SMS alerts at any time using either method:

  • Reply STOP to any SMS message from StatusRooster to immediately stop all SMS notifications.
  • In-app: Edit the monitor, toggle SMS off or remove the phone number, and save.

For help, reply HELP to any SMS message or contact support@statusrooster.com.

5. Data & Privacy

  • Phone numbers are stored securely and used only for sending SMS alerts via Twilio.
  • We do not share phone numbers with third parties for marketing purposes.
  • SMS delivery is handled by Twilio. Only the phone number is shared with Twilio — no other personal data.
