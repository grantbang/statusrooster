Questions? Answers.

What counts as a monitor?

Each URL you want to check = one monitor. Free gets 5, Pro gets 250.

What's the difference in check intervals?

Free monitors are checked every 5 minutes. Pro users can set a custom interval per monitor — anywhere from 60 seconds to 5 minutes — so you pick the right cadence for each site.

Do I get API access on Free?

Yes — full REST API on every plan. Create monitors, pull check data, automate your workflow. Generate an API key in Settings.

Do I need a credit card to start?

Nope. The free plan is genuinely free — 5 monitors, SSL monitoring, keyword checks, email alerts, full API, and uptime badges. No trial, no expiration.

Can I cancel Pro anytime?

Yes, cancel anytime from your dashboard. You'll keep Pro features through the end of your billing period. No questions asked.

What about status pages?

Free users get 1 public status page. Pro users get unlimited status pages plus an aggregate page showing all monitors at once.
