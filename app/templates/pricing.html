Questions? Answers.

What counts as a monitor?

Each URL you want to check = one monitor. Free gets 100, Pro gets 500.

What's the difference in check intervals?

Free monitors can be checked as often as every 60 seconds (custom per monitor). Pro users can set intervals as low as 30 seconds.

Do I get API access on Free?

Yes — full REST API on every plan. Create monitors, pull check data, automate your workflow. Generate an API key in Settings.

Do I need a credit card to start?

Nope. The free plan is genuinely free — 100 monitors, SSL monitoring, keyword checks, email + Slack + webhook alerts, full API, and uptime badges. No trial, no expiration.

Can I cancel Pro anytime?

Yes, cancel anytime from your dashboard. You'll keep Pro features through the end of your billing period. No questions asked.

What about status pages?

Free users get up to 10 public status pages. Pro users also get an aggregate page showing all monitors at once, plus custom branding (logo, colors, hide "Powered by").
